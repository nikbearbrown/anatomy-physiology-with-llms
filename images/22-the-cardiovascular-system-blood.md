# Images Reference: Blood (Chapter 22)

## Figures Referenced in Chapter Draft

1. **Opening montage (suggested):** Centrifuge tube showing plasma separation with clear blood layers
   - Purpose: Establish visual for composition section
   - Key elements: Dark red bottom layer (RBCs), pale thin band (buffy coat), pale straw liquid (plasma)
   - Source analogy: Geological core layering

2. **Blood cell hierarchy** (suggested)
   - RBC: biconcave disk, 7–8 micrometers
   - WBC: spherical/irregular, 10–20 micrometers (various types)
   - Platelet: fragment, 2–4 micrometers
   - Scale reference: relative sizes

3. **Hemoglobin structure** (referenced in concept two)
   - Four globin chains (alpha 1, 2, beta 1, 2)
   - Heme groups with iron atoms
   - Oxygenated (bright red) vs. deoxygenated (darker red) states
   - Cooperativity geometry (shape change on oxygen binding)

4. **RBC lifecycle** (referenced in concept two)
   - Bone marrow production (reticulocyte → mature RBC)
   - 120-day circulation
   - Senescence and macrophage recognition
   - Hemoglobin breakdown: heme → biliverdin → bilirubin → bile/stercobilin/urobilin
   - Iron recycling via ferritin and transferrin

5. **Altitude acclimatization** (worked example, concept two)
   - Kidney oxygen sensing
   - EPO release
   - Bone marrow RBC production acceleration
   - Hematocrit rise over days
   - Optional: altitude profile (sea level → 10,000 ft)

6. **Hemostasis cascade** (concept three)
   - Step 1: Vascular spasm (smooth muscle contraction)
   - Step 2: Platelet plug formation (sticky platelets, collagen binding, von Willebrand factor)
   - Step 3: Coagulation (extrinsic, intrinsic, common pathways)
   - Fibrin mesh formation and platelet/RBC entrapment

7. **Coagulation pathways** (concept three, optional detailed diagram)
   - Extrinsic pathway: tissue damage → TF (factor III) + Ca²⁺ + factor VII → factor X activation
   - Intrinsic pathway: foreign contact → factor XII → XI → IX + VIII (complexes)
   - Common pathway: factor X → prothrombin (II) → thrombin → fibrinogen (I) → fibrin
   - All 12 clotting factors labeled

8. **Fibrinolysis** (concept three, late phase)
   - Stable clot with tight platelet aggregation
   - Plasminogen → plasmin activation
   - Fibrin mesh degradation
   - Vessel wall relaxation (bradykinin)

9. **Bruise color progression** (worked example, concept two—optional visual)
   - Fresh: bright red (oxyhemoglobin)
   - Hours: dark red/purple (deoxyhemoglobin)
   - Days: blue/green (biliverdin)
   - 1–2 weeks: yellow/brown (bilirubin, stercobilin)
